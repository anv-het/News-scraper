# Groww Scraper

A Python-based scraper that fetches **stock listings** and **company news** from [Groww](https://groww.in) using `curl_cffi` with Chrome TLS impersonation.

## How It Works

Groww's APIs require an `x-request-checksum` header generated by obfuscated client-side JavaScript. `curl_cffi` impersonates Chrome's TLS fingerprint at the protocol level, making requests appear as if they come from a real browser — **bypassing the checksum requirement entirely**.

## Features

- **Stock Fetcher** — Paginates through all ~4400+ stocks on Groww
- **News Fetcher** — Fetches all news articles for each company with full pagination
- **Per-company output** — Saves as `CompanyName-ISIN.json` and `.csv` in separate folders
- **MongoDB support** — Optional upsert of news data into MongoDB
- **Cron scheduler** — Cross-platform (Windows + Linux), runs at a random time within a configurable daily window
- **Anti-detection** — Random delays between requests, periodic breaks after N stocks
- **Configurable** — Everything controlled via `.env`

## Setup

```bash
# Install dependencies
pip install -r requirements.txt
```

**Requirements:** Python 3.8+, `curl_cffi`, `python-dotenv`

## Usage

### 1. Fetch All Stocks

```bash
python fetch_stocks.py
```

Downloads the full stock list from Groww and saves to `output/groww_stocks.json`.

### 2. Fetch News for All Stocks

```bash
python fetch_news.py
```

Reads the stock list from `groww_stocks.json`, then for each company:
- Hits `GET /groww-news/v2/stocks/news/{growwContractId}?page=0&size=50`
- Paginates until empty results
- Saves `CompanyName-ISIN.json` → `output/news/json/`
- Saves `CompanyName-ISIN.csv` → `output/news/csv/`

### 3. Run as Cron Job

```bash
# First enable in .env: CRON_ENABLED=true
python cron_runner.py
```

The cron runner:
1. Picks a **random time** within `CRON_START_TIME` — `CRON_END_TIME` (system local time)
2. Sleeps until that time
3. Auto-refreshes the stocks list via `fetch_stocks`
4. Fetches news for all companies via `fetch_news`
5. Waits `CRON_DAY_GAP` days, picks a new random time, repeats

Works on both **Windows** and **Linux** — uses `time.sleep()`, no OS-specific schedulers.

## Configuration (.env)

### Output Settings

| Variable | Default | Description |
|---|---|---|
| `OUTPUT_DIR` | `output` | Stocks list output directory |
| `OUTPUT_FORMAT` | `json` | Output format: `json`, `csv`, or `both` |
| `NEWS_JSON_DIR` | `output/news/json` | News JSON output directory |
| `NEWS_CSV_DIR` | `output/news/csv` | News CSV output directory |
| `NEWS_PAGE_SIZE` | `50` | Articles per news API page (fixed) |

### Stock Scraper Settings

| Variable | Default | Description |
|---|---|---|
| `PAGE_SIZE` | `50` | Stocks per API page (max ~100) |
| `SORT_BY` | `NA` | Sort field: `NA`, `MARKET_CAP`, `CLOSE_PRICE`, `CHANGE_PERCENTAGE` |
| `SORT_TYPE` | `ASC` | Sort order: `ASC` or `DESC` |

### Stock Filter Settings

| Variable | Default | Description |
|---|---|---|
| `MIN_PRICE` | `0` | Minimum close price filter |
| `MAX_PRICE` | `500000` | Maximum close price filter |
| `MIN_MARKET_CAP` | `0` | Minimum market cap filter |
| `MAX_MARKET_CAP` | `3000000000000000` | Maximum market cap filter |

### Delay & Break Settings

| Variable | Default | Description |
|---|---|---|
| `MIN_DELAY` | `2` | Minimum random delay between requests (seconds) |
| `MAX_DELAY` | `6` | Maximum random delay between requests (seconds) |
| `REQUEST_TIMEOUT` | `30` | HTTP request timeout (seconds) |
| `BREAK_AFTER_STOCKS` | `100` | Take a break after every N stocks |
| `BREAK_MIN_MINUTES` | `5` | Minimum break duration (minutes) |
| `BREAK_MAX_MINUTES` | `15` | Maximum break duration (minutes) |

### Cron Job Settings

| Variable | Default | Description |
|---|---|---|
| `CRON_ENABLED` | `false` | Enable/disable cron mode |
| `CRON_DAY_GAP` | `1` | Number of days between runs |
| `CRON_START_TIME` | `09:00` | Earliest run time (24h, system local time) |
| `CRON_END_TIME` | `20:00` | Latest run time (24h, system local time) |

### Logging

| Variable | Default | Description |
|---|---|---|
| `LOG_LEVEL` | `INFO` | Log level: `DEBUG`, `INFO`, `WARNING`, `ERROR` |
| `LOG_TO_FILE` | `true` | Write logs to `logs/` directory |

### MongoDB (News Only)

| Variable | Default | Description |
|---|---|---|
| `MONGODB_ENABLED` | `false` | Enable MongoDB storage for news |
| `MONGODB_URL` | `mongodb://localhost:27017` | MongoDB connection string |
| `MONGODB_DATABASE` | `groww` | Database name |
| `MONGODB_COLLECTION` | `news` | Collection name |

## API Endpoints Used

| Endpoint | Method | Auth | Description |
|---|---|---|---|
| `/v1/api/stocks_data/v1/all_stocks` | POST | TLS impersonation | All stocks with filters & pagination |
| `/v1/api/groww-news/v2/stocks/news/{contractId}` | GET | TLS impersonation | News for a specific company |
